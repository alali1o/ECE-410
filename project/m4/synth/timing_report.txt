========================================================================
Path type : Setup (worst negative slack)

Critical path (estimated, technology-independent):

  clk (rise)
    → spi_slave: rx_shift FF (SDFFE_PN0P) — clock-to-Q: ~0.3 ns
    → spi_slave: bit_cnt comparison / addr_latch decode: ~0.8 ns
    → kws_top: bus_wr / bus_addr mux to compute_core.start: ~0.3 ns
    → compute_core: w_mem array read and ternary decode: ~0.5 ns
    → compute_core: 32-bit Brent-Kung adder (acc update): ~1.5 ns
    → compute_core: acc FF (SDFFE_PN0P) setup: ~0.1 ns
  -----------------------------------------------------------------
  Estimated combinational depth : ~3.5 ns
  Estimated setup slack          : +10.0 - 3.5 - 0.5 (hold margin)

========================================================================
NOTES
========================================================================
  - Full STA requires OpenLane 2 / Synopsys DC with sky130 PDK timing
    libraries. These numbers are estimated from sky130 typical gate
    delays (NAND2: ~0.05 ns/stage, DFF: Tclk-q ~0.3 ns, Tsetup ~0.1 ns).
  - The compute_core critical path (32-bit Brent-Kung adder) dominates
    and was characterized at ~1.5 ns in the M3 analysis (CF07), giving
    +8.5 ns slack at 100 MHz. The full kws_top adds ~1.5 ns of SPI
    decode overhead, reducing slack to an estimated +6.0 ns.
  - Production parameters (N_IN=1960, N_OUT=512) do not change the
    critical path depth — only the weight memory and accumulator array
    widen, but the adder tree depth (log2(N_IN) ≈ 11 levels) remains
    bounded. Timing is expected to close at 100 MHz for production.
